# Подготовка Амаля к собеседованию в Т Банк

Материалы для собеседования в команду внутренней платформы управления партнёрами и PIP Admin. Основной акцент вакансии — Django, базы данных, тестирование и интеграции. Подготовлено 11 ноября 2026 года.

Главная связь с опытом: в Яндексе Амаль разрабатывал бэкенд админки платформы A/B-экспериментов на Django; в Т-Банке работал со шлюзом к ML/VLM-моделям, доступами, ограничением нагрузки и подготовкой сервисов к эксплуатации.

## Быстрый старт

1. Проговорить [короткий рассказ о себе](docs/03-introduction-short.md).
2. Разобрать [вопросы по рабочему опыту](docs/05-experience-questions.md).
3. Восстановить фактические детали из [списка уточнений](docs/11-details-to-recall.md).
4. Повторить [техническую базу](docs/06-technical-review.md).
5. Выбрать пять [вопросов команде](docs/09-questions-for-team.md).

## Как пользоваться ответами

Разделы «Ответ по опыту» описывают задачи, которые обсуждались в переписке. Разделы «Техническое объяснение» и «Если проектировать сейчас» содержат общие подходы: их нельзя автоматически выдавать за реализацию рабочего проекта.

Неизвестные алгоритмы, пороги, показатели нагрузки, точные результаты измерений и конкретные инциденты не выдуманы. Они вынесены в отдельный список для восстановления. Число часов и порядок подготовки — предложенный план, а не информация о формате интервью.

Материалы предназначены для подготовки к собеседованию. Здесь нет исходного кода работодателей, токенов, внутренних URL или загруженных скриншотов.

## Три главные истории

- **Яндекс:** админка платформы, этап подготовки ресурсов для ML-экспериментов, конфигурации в YT, интеграции и e2e-тесты, вывод в продакшен.
- **Т-Банк:** API-шлюз к ML/VLM, валидация, JWT/JWKS и scopes, лимиты в Valkey, circuit breaker по моделям.
- **Эксплуатация:** общие библиотеки, тестирование, мониторинг, runbooks, описание зависимостей и контракты данных.

Признак готовности: по каждой истории можно объяснить цель, личный вклад, устройство решения, ошибочные сценарии, проверку и результат.
